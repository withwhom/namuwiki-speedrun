# 나무위키 스피드런

크롬에서 나무위키를 직접 돌아다니며 하는 게임입니다. 시작 문서에서 **본문 링크만 눌러서** 목표 문서까지 가면 됩니다.
확장은 페이지 위에 타이머, 클릭 수, 지나온 경로만 얹습니다.

## 설치

빌드 과정은 없습니다. `extension/` 폴더를 그대로 불러옵니다.

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/withwhom/namuwiki-speedrun.git
   ```
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램 로드**를 누르고 저장소 안의 **`extension` 폴더**를 고릅니다. 저장소 최상위 폴더가 아닙니다.
5. 툴바의 퍼즐 아이콘에서 "나무위키 스피드런"을 고정하면 쓰기 편합니다.

코드를 고친 뒤에는 `chrome://extensions`에서 확장의 새로고침 버튼을 누르고, 열려 있는 나무위키 탭도 새로고침하세요.

## 게임 방법

툴바 아이콘을 눌러 팝업을 엽니다.

- **오늘의 문제**: 날짜마다 정해진 시작 → 목표 한 쌍입니다. 한국 시간 자정에 바뀌고, 번호(#1, #2 …)가 붙습니다.
- **랜덤 도전**: 서로 관계없는 문서 1800여 개를 28개 분야(음식, 인물, 추상 개념, 군사, 캐릭터 등)로 모은 문서 모음(`extension/data/pool.json`)에서 시작 문서와 목표 문서를 따로 하나씩 뽑습니다. 분야를 먼저 고르게 고르고 그 안에서 문서를 고르므로, 어느 분야든 비슷한 빈도로 나옵니다. "다른 문제"를 누르면 다시 뽑습니다.
- **직접 입력**: 시작 문서와 목표 문서 이름을 직접 적습니다. 거의 쓰지 않아 팝업 맨 아래에 접어 두었습니다.

시작을 누르면 새 탭에 시작 문서가 열리고 타이머가 돕니다. 오른쪽 위 HUD에 경과 시간, 클릭 수, 목표 문서, 지나온 경로가 나옵니다.
HUD는 위쪽 띠를 끌어서 옮길 수 있고 ▾ 버튼으로 접을 수 있습니다. 위치와 접힘 상태는 기억됩니다.

목표 문서에 도착하면 타이머가 멈추고 결과 화면이 뜹니다. 결과 화면에서 공유 문구를 복사할 수 있습니다.

```
나무위키 스피드런 #12
짜장면 → 아이작 뉴턴
5클릭 · 2:13
```

### 규칙

- 새 문서(`/w/…`)로 이동할 때마다 1클릭입니다. **뒤로/앞으로 가기도 1클릭**이고, 경로에 ↩로 표시됩니다.
- 아래로 가면 경고가 뜨고 기록에 **규칙 위반**이 남습니다. 게임은 계속됩니다.
  - `분류:`, `파일:`, `틀:`, `나무위키:`, `사용자:` 같은 이름공간 문서. 클릭 수에도 들어갑니다.
  - 편집, 역링크, 역사, 검색, 토론처럼 문서가 아닌 페이지. 경로에만 남고 클릭 수에는 들어가지 않습니다.
  - 주소창에 직접 입력하거나 북마크로 이동한 경우.
- 게임 중에는 나무위키 검색창을 숨깁니다.
- 게임 중에는 브라우저 찾기 단축키(Ctrl+F, 맥은 ⌘F, 다음 찾기 F3·Ctrl+G)를 막습니다. 크롬 메뉴로 여는 찾기는 막을 수 없습니다.
- 목표 문서 도착은 띄어쓰기와 영문 대소문자를 무시하고 판정합니다 (예: `레오나르도 다 빈치` = `레오나르도 다빈치`).
- 규칙 위반이 있는 기록과 포기한 기록은 최고 기록에서 빠집니다.
- 최고 기록은 클릭 수가 적은 쪽이 앞서고, 같으면 시간이 짧은 쪽이 앞섭니다.
- 게임 탭을 실수로 닫았다면 팝업의 **게임 탭 다시 열기**로 마지막 문서부터 이어 갈 수 있습니다. 타이머는 계속 흐릅니다.

기록은 이 컴퓨터의 크롬(`chrome.storage.local`)에만 저장되고, 어디로도 보내지 않습니다.

## 권한이 필요한 이유

| 권한 | 이유 |
| --- | --- |
| `storage` | 진행 중인 게임, 최근 기록, 최고 기록, HUD 위치를 이 컴퓨터에 저장합니다. |
| `webNavigation` | 게임 탭이 어느 주소로 이동했는지 알아내서 클릭 수를 세고 규칙 위반을 판정합니다. 나무위키는 새로고침 없이 주소만 바꾸며 이동하기도 해서, 일반 페이지 로드와 history 기반 이동을 모두 봐야 합니다. 이동 방식(링크, 뒤로 가기, 주소창 입력)도 여기서 알 수 있습니다. |
| `https://namu.wiki/*` | 나무위키 페이지 위에 HUD를 그리고 검색창을 숨기는 스크립트를 넣기 위해 필요합니다. 다른 사이트에는 접근하지 않습니다. |

확장은 나무위키로 따로 요청을 보내지 않습니다. 사용자가 보는 탭의 주소만 관찰합니다. 외부 서버, 원격 코드, 분석 도구도 쓰지 않습니다.

## 개발

Node.js 20 이상이 필요합니다.

```bash
npm test
```

순수 로직(제목 정리, 이동 판정, 규칙 위반 판정, 점수, 오늘의 문제 선택)의 단위 테스트입니다. 따로 설치할 것이 없습니다.

```bash
npm install && npx playwright install chromium && npm run test:e2e
```

Playwright로 확장을 실제로 불러와서 가짜 나무위키 페이지로 게임 흐름을 확인합니다. `https://namu.wiki/*` 요청은 테스트가 가로채 로컬 HTML로 응답하고, 그 밖의 외부 요청은 막습니다.

구조와 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다.
